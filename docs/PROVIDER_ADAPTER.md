# SIE-011 Provider adapters and credential boundaries

Provider integrations implement streaming, asynchronous submission, polling and optional cancellation through one tested contract. Two independent fake adapters are included solely for conformance tests; they are **not actual AI providers** and are never advertised as available. Every dispatch verifies an explicit model operation, region, rights and a **trusted budget reservation** (never a user-submitted Boolean), resolves its environment secret only server-side, and enforces abort/timeout rules. Administrative logger gets limited event metadata and no credentials or prompts. This is an execution adapter boundary, not SIE-012 live inference, actual invoice reconciliation or persistent queue. The latter require explicit authenticated deployment secrets and real providers.
